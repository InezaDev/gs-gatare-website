# Groupe Scolaire Gatare — Website

A responsive, static school website built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in a browser. For a local development server, use VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `gs-gatare-website`).
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site; the public URL will appear in the Pages settings.

## Important customization before publishing
- Replace the illustrative Unsplash background photographs with school-approved photos.
- Confirm the official welcome message, mission, vision, values and exact programs with school leadership.
- Confirm current admission requirements, dates and any fees with the school.
- The forms currently prepare an email via the visitor's email application. They do not save submissions to a database. For online storage, connect a trusted form backend or school-managed endpoint.
- The map section links to a Google Maps search for Gatare Sector; verify the precise school pin and replace the link if needed.
- Add verified news and announcements before presenting them as current updates.
